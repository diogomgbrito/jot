# Releasing

Jot ships as an ad-hoc signed (not notarized) universal DMG on GitHub Releases, installed through Homebrew. This repo is its own tap: the cask is `Casks/jot.rb`. The cask removes the quarantine flag after install, so Gatekeeper doesn't block the app.

Install:

```bash
brew tap diogomgbrito/jot https://github.com/diogomgbrito/jot
brew trust diogomgbrito/jot
brew install --cask jot
```

## Release a new version

1. Bump `CFBundleShortVersionString` (and `CFBundleVersion`) in `Resources/Info.plist`, e.g. `1.0.1`.
   Move the `[Unreleased]` notes in `CHANGELOG.md` under the new version.
2. Build the DMG:
   ```bash
   scripts/release.sh
   ```
   Prints the version, `build/Jot-<version>.dmg` and its SHA256.
3. Update `version` and `sha256` in `Casks/jot.rb` with the values the script printed. Don't rebuild after this: every build changes the SHA.
4. Commit, tag and push:
   ```bash
   git commit -am "Release 1.0.1"
   git tag v1.0.1
   git push origin main v1.0.1
   ```
5. Create the GitHub release with the DMG:
   ```bash
   gh release create v1.0.1 build/Jot-1.0.1.dmg --title "Jot 1.0.1" --notes-file <(awk '/^## \[1.0.1\]/{f=1;next} /^## \[|^\[/{f=0} f' CHANGELOG.md)
   ```
Users then get it with `brew upgrade --cask jot`.

## Notes

- The DMG file name must match the cask URL: `Jot-<version>.dmg` under tag `v<version>`.
- The repo must be public: Homebrew downloads the DMG without credentials.
- The app icon is generated by `swift scripts/make-icon.swift`.
